# IMDb Movie Rating Scraper

A Python-based web scraper built using Selenium and Pandas to extract the Top 250 movies from IMDb along with their ratings and store them structured in a CSV file.

## Tech Stack
* **Python**
* **Selenium** (Web Automation & Scraping)
* **Pandas** (Data Analysis & CSV Generation)

## Features
* Automatically navigates to IMDb Top 250.
* Extracts movie titles, ratings, and details robustly.
* Saves the collected dataset into `imdb_top_250.csv`.
